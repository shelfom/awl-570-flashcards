# AWL 570 Flashcards · 学术词汇表 570 词卡

All 570 headwords of the Academic Word List — the vocabulary of IELTS, TOEFL and university reading.

学术词汇表全部 570 个词族，雅思、托福和大学阅读的核心词汇。

**Free · no sign-up · works on phones.** Part of [Free English Learning Tools](https://github.com/shelfom/free-english-learning-tools), 11 free websites for IELTS, Cambridge English and academic vocabulary.

**[▶ Open the site](https://awl-flash.coze.site/)** (fastest in mainland China) · **[🌍 Global mirror](https://shelfom.github.io/awl-570-flashcards/)** (GitHub Pages)

[![AWL 570 Flashcards screenshot](docs/screenshot.jpg)](https://awl-flash.coze.site/)

## What's inside

- 570 headwords in the 10 official sublists
- UK and US pronunciation, IPA, Chinese meaning, plain-English definition
- Collocations and an example sentence on every card
- Progress saved across sessions; works on phones

```bash
pnpm install
pnpm dev
```
